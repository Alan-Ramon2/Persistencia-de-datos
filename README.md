Proyecto de Persistencia de Datos - Indurama

Este proyecto implementa el mapeo ORM de la empresa Indurama con 5 entidades:
- Producto
- Categoría
- Proveedor
- Distribuidor
- Mantenimiento

Incluye las relaciones JPA (`@ManyToOne`, `@OneToMany`, `@ManyToMany`) y 3 consultas JPQL (filtro, paginación y `LEFT JOIN FETCH`) desarrolladas para la Tarea de la Unidad 3.
